# 🍵 Abartılı Çay Molası Simülatörü

Bu repository, insanlık tarihinin en önemli problemini çözmek için yaratılmıştır: **Çay molası ne zaman gelmeli?**

## Nedir Bu?

Tamamen bilimsel, tamamen ciddi, tamamen abartılı bir çay molası hesaplayıcısı. Kod gerçekten çalışır. Gerçekten. Deneyin ve pişman olmayın.

### Özellikler
- Dramatik bekleme süreleri
- Felsefi çay sözleri
- Abartılı hesaplamalar
- Hiçbir işe yaramayan ama çok komik çıktılar

## Nasıl Çalıştırılır?

```bash
python cay_molasi.py
```
